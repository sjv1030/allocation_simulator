Two-Bucket Allocation Simulator

Shortfall analysis for a bond/equity portfolio against a compounding guarantee. Each sleeve is simulated as its own GBM from an annual return and volatility assumption, with the cross-asset correlation taken from history. Set the guarantee, the horizon, and your capital-market assumptions, then re-run in the browser.

Terminal shortfall probability across the allocation grid
